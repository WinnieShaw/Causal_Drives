# Figures

`pdf/` contains reproducible, text-free manuscript figures. Plot sources live in
`source/`; the corrected-results scripts run from the repository root and
consume only the compact derived inputs in `../data/derived/`.

The qualitative case-panel script expects local case metadata and original
images that are not distributed here. The underlying benchmark has to be
obtained from its upstream source first. The original-image case PDF is omitted
from this public release for the same reason.
