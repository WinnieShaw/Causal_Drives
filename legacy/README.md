# Preserved earlier release

`initial_release/` preserves the files that were present at the repository's
original public commit. The code there computes the earlier probability-domain
version of the metrics and is not compatible with the current log-domain
results in the root README. Its MiraData question files are retained for
provenance and are not part of the current paper's reported experiments.

The files were moved rather than deleted so the repository history and the
original release remain inspectable. Use the current `experiments/` and
`data/derived/` paths for the present release.
